# Sachin Bains — Engineering & Computation

Personal portfolio exploring computational research, aerospace engineering and quantitative systems.

**Website:** https://sachin-bains.github.io/

Current case studies:

- [Turbulence surrogates and uncertainty](https://sachin-bains.github.io/turbulence.html)
- [C++20 limit order book and matching engine](https://sachin-bains.github.io/matching-engine.html)
- [Hypersonic plume–surface interaction](https://sachin-bains.github.io/hypersonic.html)

The portfolio is under active development. This repository contains the published static website, browser modules and supporting public research exhibits. Full working research folders and private development notes are maintained separately.

## Publication

GitHub Pages serves `main` from the repository root. `.nojekyll` preserves the existing HTML/CSS/JavaScript site without a theme or generator. Updates to `main` publish at the same address.

The C++ exhibit runs its compiled WebAssembly module. Research interactions distinguish original numerical exports, archived figures, approximate digitisation and analytical reference calculations. Source attribution and evidence limitations are retained within each project.

No package installation or build is required to serve this snapshot. For local preview, use any static HTTP server from this directory; module scripts cannot be tested by opening the HTML directly as a local file.
